## 🧠 Overview

Portraiture is a skin retouching plug-in from Imagenomic: it smooths skin while keeping texture, evens out blemishes and tonal patches, and exposes the result through sliders for softness, warmth and detail.

On a Windows machine it runs as a plug-in suite that loads inside Adobe Photoshop CC 2019 or newer, Adobe Lightroom Classic. Typical use is skin retouching plug-in work on local files, so the application does not need a subscription or a cloud project to open and save documents.

## Additional Information for Windows Users

Settings created in Imagenomic Portraiture are stored in the plug-in's own preset folder, so a reinstall keeps user presets and replaces only program files.

Removing the plug-in goes through the host application's plug-in manager or the Windows uninstall entry, depending on how it was registered.
